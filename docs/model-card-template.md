# Model card template

Each artifact renders the following information from immutable run metadata:

- model version and selected estimator family;
- intended offline comprehensive-car-insurance use and saved domain;
- validation selection policy and latency ceiling;
- conformal method, nominal coverage, calibration count, and radius;
- independent audit MAE, RMSE, WAPE, R², p95/max absolute error, bootstrap
  confidence bounds, interval coverage/width, and predefined risk slices;
- constrained-versus-unconstrained accuracy tradeoff;
- provider and dependency provenance without quote payload logs;
- promotion gate state and all warnings;
- governance and regulatory limitations.

Product owners should append ownership, approval dates, training-data lawful
basis, jurisdiction, monitoring thresholds, incident contacts, and retirement
date without deleting generated limitations.
