# Model card reference

Every exported artifact contains a rendered `model-card.md` built from
immutable run metadata. It records intended use, model selection and monotonic
tradeoffs, conformal calibration, complete held-out audit metrics and risk
slices, promotion gates, provider and dependency provenance, warnings, and
governance limitations.

The rendered card is hash protected. Organization-specific ownership,
approvals, lawful basis, monitoring, incident, and retirement details belong in
an external governance record tied to the artifact identity.
